# Claude Build Instructions

Before designing or editing this site, read `BUILD_PLAYBOOK.md`, `CLIENT_HANDOFF.md`, and `CLAUDE_DESIGN_HANDOFF.md` if present.

Do not rely on memory for recurring site-build requirements. Use the playbook and run `python3 scripts/preflight.py` before handoff.

When handing off design direction, include concrete tokens: logo files, colors, fonts, imagery, page inventory, component direction, menu/PDF links, form/VIP requirements, and any deliberate exceptions.

Gotchas are tracked in `GOTCHAS.md`; update it whenever a build mistake or audit trap is discovered so future sessions do not repeat it.
