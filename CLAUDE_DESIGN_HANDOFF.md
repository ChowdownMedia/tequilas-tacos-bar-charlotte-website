# Claude Design Handoff Requirements

Use this when Claude Design or another designer hands work to the build agent.

## Required Design Tokens

- Logo usage and contrast rules.
- Color palette with hex values.
- Font choices and local font files or licensed source.
- Button styles.
- Nav/header behavior desktop and mobile.
- Footer layout and required links.
- Image treatment: crops, overlays, aspect ratios, hover states.
- Card/grid rules for desktop and mobile.
- Form styling and states.

## Required Pages

- Home.
- Food menu.
- Seafood menu.
- Drinks menu.
- Menu category/detail pages.
- Gallery.
- Events.
- VIP.
- Contact/footer sections.

## Required UX Notes

- How users switch between menus.
- How users return from category/detail pages.
- Order online placement.
- Download PDF placement.
- Mobile tap target expectations.
- Desktop space usage expectations.

## Required Assets

- Logo variants.
- Favicon/app icons.
- Font files.
- Hero images.
- Menu category image mapping.
- Gallery image set.
- PDF files or URLs.

## Handoff Acceptance

The design handoff is incomplete until it includes concrete files/URLs and enough direction for a builder to produce the site without guessing core brand, layout, or integration behavior.
